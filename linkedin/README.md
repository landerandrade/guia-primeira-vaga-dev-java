# LinkedIn para Dev Java Júnior

LinkedIn não é onde você candidata para vaga. É onde o recrutador te acha — ou não.

---

## Como o recrutador usa o LinkedIn

Recrutador técnico abre o LinkedIn, digita palavras-chave no campo de busca de pessoas e filtra por localização. Se seu perfil não tem as palavras certas, você não aparece — independente de quão bom você seja.

As palavras que ele digita: `Java Developer`, `Java Junior`, `Spring Boot`, `Desenvolvedor Java`.

---

## Título profissional

Esse campo é o mais indexado pelo algoritmo. Use:

```
Desenvolvedor Java Júnior | Spring Boot | REST API | Em busca de oportunidade
```

Não use:
- "Estudante de TI" — não aparece na busca de devs
- "Apaixonado por tecnologia" — não diz nada técnico
- "Desenvolvedor Full Stack" — se você não tem comprovação, não use

---

## Foto

Foto profissional com fundo neutro. Sem selfie de festa, sem foto cortada de grupo.

LinkedIn com foto tem 21x mais visualizações de perfil do que sem foto (dado da própria plataforma).

---

## Seção "Sobre"

3–4 parágrafos curtos:

1. O que você faz tecnicamente (stack, tipo de projeto)
2. O projeto que você está construindo ou construiu
3. O que você busca (cargo, tipo de empresa, área)
4. Como entrar em contato

Exemplo:
> Desenvolvedor Java com foco em backend e APIs REST com Spring Boot.
>
> Construí o TaskForge — uma API de gerenciamento de tarefas com autenticação JWT, PostgreSQL e Docker, desenvolvida do zero seguindo as práticas de um time real: branches, Pull Requests e code review.
>
> Busco minha primeira oportunidade como desenvolvedor júnior — empresas que valorizam qualidade de código e têm cultura de aprendizado contínuo.
>
> Me chama no LinkedIn ou pelo e-mail: [seu email]

## Experiências

**Sem experiência formal?** Adicione seus projetos como experiência.

```
Projeto Pessoal — Desenvolvedor Java
Jan 2025 – atual

Desenvolvimento do TaskForge: API REST de gerenciamento de tarefas
construída com Java 21, Spring Boot, Spring Security (JWT),
PostgreSQL e Docker.

• Implementei autenticação e autorização com JWT
• Modelei o banco de dados com JPA/Hibernate e Flyway para migrações
• Configurei ambiente de desenvolvimento com Docker Compose
• Documentei a API e publiquei o código no GitHub

github.com/seu-usuario/taskforge-api
```

Isso é legítimo. Projeto pessoal é experiência real.

## Habilidades (Skills)

Adicione e ordene as skills por relevância:

**Obrigatórias:** Java, Spring Boot, Spring Framework, REST APIs, SQL, Git, GitHub, Docker

**Opcionais se tiver:** Spring Security, JPA, Hibernate, Maven, PostgreSQL, Redis, JWT

Peça para 3–5 pessoas endossarem (colleagues, colegas de curso). Endosso aumenta relevância no algoritmo.

---

## Formação

Adicione todos os cursos relevantes como formação:
- Cursos de Java/Spring Boot (Udemy, Alura, etc.)
- Bootcamps
- Faculdade (se tiver)

Período: mesmo que ainda esteja cursando, coloque como "em andamento".

---

## Atividade: o que postar

Você não precisa ser influencer. Mas alguma atividade ajuda.

O que funciona para dev júnior:
- O que aprendeu essa semana (1 parágrafo)
- Dúvida que tinha e como resolveu
- Projeto que concluiu (com link do GitHub)
- Artigo técnico que leu com seu comentário

Frequência: 1–2 posts por semana é suficiente.

---

## Abrir para oportunidades

Vá em: Eu → Configurações → Preferências de emprego → "Aberto para oportunidades"

Marque como visível para recrutadores. Isso aumenta sua visibilidade nas buscas.

---

## Checklist do LinkedIn

- [ ] Foto profissional
- [ ] Título com Java + Spring Boot + "Em busca de oportunidade"
- [ ] Seção Sobre preenchida com stack e projeto
- [ ] Projeto pessoal adicionado como experiência com link
- [ ] Skills relevantes adicionadas
- [ ] Aberto para oportunidades ativado
- [ ] URL personalizada (linkedin.com/in/seu-nome)
