# Currículo para Dev Java Júnior

Sem experiência formal, o currículo precisa fazer um trabalho diferente: provar que você sabe codar antes de o recrutador abrir seu GitHub.

---

## O que o recrutador vê em 10 segundos

1. Nome e contato
2. Stack (Java, Spring Boot, SQL — palavras exatas)
3. Se tem projeto listado com link
4. Formação

Se esses quatro pontos não estiverem claros em 10 segundos, o currículo vai pro próximo.

---

## Estrutura que funciona

```
Nome — Desenvolvedor Java Júnior
Email · LinkedIn · GitHub · Cidade/UF

SOBRE
2–3 frases. O que você sabe fazer, qual stack domina, o que busca.
Exemplo: "Desenvolvedor Java com foco em Spring Boot e APIs REST.
Construí o backend do [projeto] do zero, com autenticação JWT,
integração com banco PostgreSQL e deploy em nuvem. Busco primeira
oportunidade como desenvolvedor júnior."

HABILIDADES TÉCNICAS
Java 17+ · Spring Boot · Spring Data JPA · Spring Security
REST API · PostgreSQL · Git · Docker (básico)

PROJETOS
[Nome do projeto] — github.com/seu-usuario/nome-do-repo
Descrição em 1–2 linhas do que faz e qual problema resolve.
Stack: Java 21, Spring Boot, PostgreSQL, Docker

FORMAÇÃO
[Curso / Faculdade] — Conclusão: Ano
```

## Erros mais comuns

**Objetivo genérico demais**
> "Busco oportunidade para crescer profissionalmente e aplicar meus conhecimentos"

Isso não diz nada. Seja específico: qual cargo, qual stack, qual valor você traz.

**Lista de tecnologias sem contexto**
Não escreva só "Java, Spring, SQL". Mostre onde usou.

**Projeto sem link**
Se não tem GitHub, não existe. Todo projeto no currículo precisa de link.

**Página e meia de currículo**
Uma página. Sempre. Recrutador não vai ler mais.

**PDF gerado por Word com formatação quebrada**
Use o [Reactive Resume](https://rxresu.me/) (gratuito, exporta PDF limpo) ou o Canva se preferir visual.

---

## O que colocar quando não tem experiência

Em ordem de peso para o recrutador:

1. **Projeto próprio com código no GitHub** — o mais importante
2. **Projetos de curso** — se o código está no GitHub e funciona
3. **Contribuição em open source** — mesmo que pequena
4. **Freelance** — mesmo que para amigo ou projeto pessoal
5. **Formação técnica** — curso, bootcamp, faculdade

Se você não tem nenhum projeto: esse é o problema a resolver antes do currículo.

---

## Palavras que o ATS (filtro automático) procura

Inclua essas exatamente como estão escritas:

- Java
- Spring Boot
- Spring Framework
- REST API
- JPA / Hibernate
- PostgreSQL / MySQL
- Git / GitHub
- Docker
- Maven

Sistemas ATS leem texto puro. Se o seu PDF é uma imagem ou tem tabelas complexas, o filtro não lê nada.

---

## Checklist antes de enviar

- [ ] Tem link do GitHub no cabeçalho
- [ ] Tem pelo menos um projeto com link clicável
- [ ] Stack listada com palavras exatas (Java, Spring Boot, não "back-end frameworks")
- [ ] Uma página
- [ ] PDF gerado corretamente (não é imagem)
- [ ] Email e LinkedIn atualizados
- [ ] Sem erros de português
