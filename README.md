# Guia: Primeira Vaga como Desenvolvedor Java

> Escrito por um dev sênior que já esteve exatamente onde você está agora.

Você estuda Java há meses — talvez mais de um ano. Consegue seguir tutoriais, entende a lógica, mas na hora de construir algo do zero trava. Mandou currículos, não teve resposta. Fez entrevista e não foi chamado de volta.

Esse guia é direto ao ponto. Sem promessa de "aprenda em 30 dias". Sem fórmula mágica. O que funciona, o que não funciona, e o que ninguém te conta sobre entrar na área.

## A verdade que ninguém fala

A maioria dos devs júnior é rejeitada não porque não sabe programar.

É rejeitada porque:
- O currículo não passa nem pelo filtro automático
- O GitHub está vazio ou cheio de projetos inacabados
- Na entrevista, não sabe explicar o que fez nem por quê
- Nunca abriu um Pull Request de verdade
- Nunca trabalhou com código de outra pessoa

Técnica importa. Mas o mercado contrata a pessoa inteira — não só o algoritmo que ela resolve.
